## 📱 Proyecto Final: Pokédex Flutter

Pokédex completa construida con Flutter que consume PokeAPI, con autenticación Firebase, favoritos persistentes y notificaciones locales.

### Tecnologías
- **Flutter & Dart** - Framework multiplataforma
- **Riverpod** - Manejo de estado
- **Firebase Auth** - Autenticación
- **SharedPreferences** - Persistencia local
- **Dio** - Cliente HTTP
- **Local Notifications** - Notificaciones programadas

### Características
- 🔍 Búsqueda y filtrado por tipos
- ⭐ Sistema de favoritos persistente
- 🔐 Autenticación con email/contraseña
- 🔔 Notificaciones locales programadas
- 🎨 Temas personalizables (claro/oscuro/alterno)
- 📊 Estadísticas detalladas de cada Pokémon

## 🔐 Proyecto: ShareCrypt

ShareCrypt is an Android application for secure local sharing of files and short secrets using ephemeral key exchange and end-to-end verification. It provides a simple UI for sending files, receiving secrets, managing keys, and verifying transfers — designed for private, device-to-device exchanges without relying on cloud storage.

### Tecnologías
- **Kotlin** - Lenguaje de programación
- **Android SDK** - Plataforma de desarrollo
- **Cryptography API** - Cifrado end-to-end
- **Bluetooth/WiFi Direct** - Comunicación local
