# Proyecto 1: TRON 3D - Light Cycle Battle Game

Tron 3D es un juego de batalla de motos lightcycle inspirado en Tron Legacy, donde los jugadores compiten dejando rastros de luz neón que actúan como muros letales en una arena digital.


## 🛠️ Tecnologías Principales

- **Kotlin** - Lenguaje de programación
- **LibGDX** - Framework de gráficos 3D
- **OpenGL ES** - Renderizado y efectos visuales
- **Bluetooth** - Multijugador en tiempo real
